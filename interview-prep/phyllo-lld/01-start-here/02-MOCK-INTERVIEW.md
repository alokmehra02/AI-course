# Solo Mock Interview Script (45 min)

Do this once tonight with a timer. Speak out loud.

---

## Setup

- Timer 45:00  
- Blank paper  
- No notes for first 5 minutes after the prompt (force memory)  
- Then you may glance at cheat sheets  

---

## Prompt (read to yourself)

> “Design the backend for Phyllo Connect: creators link Instagram/YouTube, grant consent for identity and engagement, Phyllo syncs data, and customer developers get notified when data is ready. Use Python for the design.”

---

## Your forced structure

| Time | Section |
|------|---------|
| 0–2 | Opening + restate |
| 2–8 | Clarifying Qs + assumptions |
| 8–15 | Entities + modules + API list |
| 15–35 | Sequence + classes + schema |
| 35–42 | Failures + webhooks + rate limits |
| 42–45 | Summary |

---

## After mock — score

Use `03-interview-flow/02-SCORING-CHECKLIST.md`.

If below 14/18:
- Re-draw Connect→Sync→Webhook once from memory  
- Re-drill 10 rapid-fire answers  
- Re-mock only the weak phase (usually schema or failures)
