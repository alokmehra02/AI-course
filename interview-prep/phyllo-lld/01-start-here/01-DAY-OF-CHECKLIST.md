# Day-of Checklist

## 60 minutes before

- [ ] Water, quiet space, stable network
- [ ] Pen + blank paper (or empty Miro / Excalidraw)
- [ ] Resume open (VoXgent + Europa bullets)
- [ ] One-pager open: `08-cheat-sheets/01-DAY-OF-ONE-PAGER.md`
- [ ] Close other tabs / Slack

## First 2 minutes of the call

- [ ] Smile, short intro if asked
- [ ] Confirm: “This is LLD — I’ll clarify requirements, then design classes/APIs/schema/flows in Python.”
- [ ] Ask if they want board-first or talk-first

## During design

- [ ] Clarify before designing
- [ ] State assumptions out loud
- [ ] Use Phyllo words: user, account, work platform, product, sync status, webhook
- [ ] Cover happy path + one failure path
- [ ] Mention idempotency + retries + rate limits at least once
- [ ] Offer depth: “I can go deeper on schema, connectors, or failure modes.”

## Last 5 minutes

- [ ] Summarize in 4 bullets
- [ ] Ask 1–2 smart questions about their team/system (see `04-what-to-say/04-QUESTIONS-FOR-THEM.md`)

## Do not

- Jump into classes before requirements
- Design UI for Connect SDK
- Invent fake ML math for authenticity scores
- Go silent for long stretches — narrate
- Apologize excessively
