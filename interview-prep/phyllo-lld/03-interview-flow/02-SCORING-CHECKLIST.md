# Self-Scoring Checklist

After a mock, score yourself 0/1 on each. Target **14+/18** before interview day.

## Process
- [ ] Clarified before designing
- [ ] Stated assumptions
- [ ] Confirmed scope with interviewer
- [ ] Narrated continuously (no long silence)
- [ ] Summarized at the end

## Design content
- [ ] Named Phyllo-like entities correctly
- [ ] Defined APIs with method + path + key fields
- [ ] Defined DB tables + at least one unique constraint / index
- [ ] Drew or described a sequence for happy path
- [ ] Covered at least one failure path
- [ ] Mentioned async boundary (queue/workers)
- [ ] Mentioned idempotency
- [ ] Mentioned retries / backoff
- [ ] Mentioned rate limiting or platform constraints
- [ ] Mentioned consent / auth / multi-tenant safety

## Python / LLD depth
- [ ] Used classes or interfaces (not only boxes)
- [ ] Adapter/strategy for platforms OR clear module boundaries
- [ ] Could write 1–2 method signatures if asked

## Presence
- [ ] Linked one resume experience naturally
- [ ] Handled a follow-up without collapsing the design
